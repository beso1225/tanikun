PRF physical probe

This page is not the product login. It creates two disposable passkeys for the approved test origin and compares PRF results only in memory. Do not use a real account, planner record, or production origin.

1. Preflight

The only approved origin is https://localhost:4300 with RP ID localhost. This page refuses to start a ceremony on any other origin, over an iframe, or without a secure context.
