# 科目の同一性は安定した科目IDで判定する

## Status

accepted

## 決定

科目の同一性は、名前ではなく安定した `科目ID` で判定する。名前は表示用の可変な属性として扱い、名前が同じでも科目IDが異なれば別の科目とする。

## 背景

科目の名前は一意でない。同名で単位数や区分が異なる科目（例: 複数学科の「物理学演習」）が存在しうるし、後から改名されることもある。当初は「同名なら同一の科目」という単純化を検討したが、衝突が起きたときの破綻が履修記録と卒業要件集計の根幹に波及するため退けた。

## Considered Options

- **名前を同一性の鍵にする**: マスタ整備の手間は最小だが、同名別科目・改名・表記ゆれで破綻する。
- **安定した科目IDで判定する（採用）**: マスタ側でIDを維持するコストはかかるが、上記の破綻が起こらない。

## Consequences

- 科目マスタと独自科目は、名前とは独立した安定IDを持つ必要がある。
- 名前の変更は同一性に影響しない。
