# 区分は要件セット側で定義し、科目は区分を持たない

## Status

accepted

## 決定

科目をどの区分に入れるかは、プログラムごとの要件セットが区分表として定義する。科目そのものは区分を持たず、既定の区分も持たない。

## 背景

同一の科目でも学科・コースによって区分が異なる。区分は「そのプログラムの卒業要件でどう数えるか」の話であり、科目マスタの属性ではない。当初は科目に区分を持たせる案を想定したが、プログラム固有の情報がマスタに滲み出し、二重管理になるため退けた。

## Considered Options

- 科目が既定の区分を持つ: 科目ごとに1つの区分しか持てず、学科・コース差を表現できない。
- 科目がプログラムごとの区分表を持つ: 表現はできるが、マスタにプログラム固有の情報が混ざる。
- 要件セットが区分表を持つ（採用）: 区分の真実が1箇所に集まり、プログラム別の差をマスタを汚さず表現できる。

## Consequences

- 科目をマスタに追加するたび、対象プログラムの要件セットの区分表も更新する。
- 表示用の区分も、選択中プログラムの要件セットから導出する。
