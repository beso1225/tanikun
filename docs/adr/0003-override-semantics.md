# 上書きは汎用レコードとし、合格時の凍結を優先する

## Status

accepted

## 決定

ユーザーの上書きは、対象（科目または開講）・属性名・値を持つ汎用レコード1種類で表す。上書きは要件の集計にも反映するが、履修が合格した時点で凍結された値（ADR-0002）を上書きが覆うことはない。

## 背景

上書きしたい属性の持ち主が一定でない。名前は科目側、曜限は開講側に属す。対象ごとに別の仕組みを作ると実装が二重になる。また、上書きを集計に効かせると、合格時に凍結した単位数と衝突しうる。

## Considered Options

- 科目の上書きと開講の上書きを別々に持つ: 属性の持ち主ごとに正しいが、実装が二重になる。
- 汎用レコード（採用）: 対象・属性名・値の1種類で、科目側も開講側も表現できる。

## Consequences

- 上書き可能な属性は運用で決める（名前・曜限は可、区分は不可、単位数は未合格の間のみ可）。
- 合格前の上書きは集計に効き、合格後は凍結が優先する。
