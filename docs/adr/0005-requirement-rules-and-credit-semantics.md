# 卒業要件は木で表し、単位の数え方を葉に閉じ込める

## Status

accepted

## 決定

卒業要件は木として表す。単位や科目を数えるのは**葉**の役割とし、節は子の充足だけを扱う。

葉:

- 区分から N 単位以上
- 区分の組から N 単位以上（単一区分はこの特殊形）
- トータル N 単位以上
- 特定の科目をすべて合格
- 特定の科目集合から N 単位以上（選択必修）

節:

- `All`（子をすべて満たす）
- `Any`（子のいずれかを満たす）
- `AtLeast(N, …)`（子のうち N 個以上を満たす）。数えるのは子の充足個数であり、単位数ではない。

単位計算では、1つの科目は1つの区分にのみ属し、区分をまたぐ重複計上はしない。一方でトータルは全合格科目の和とし、区分の要件に使った単位もトータルに加算する。区分表に無い科目はトータルにのみ数える。

## 背景

単位数の要件と要件の組み合わせを同じ演算で扱うと、「AtLeast の N は単位か個数か」が曖昧になり、実装と解釈がずれる。単位数を数える操作を葉に固定し、節は論理的な組み合わせに限定すると、意味が一意に定まる。

## Consequences

- 単位数の要件は必ず葉として書く。`AtLeast` に単位数を渡さない。
- 区分の二重所属が無いので、合格した単位をどの区分に割り当てるかの曖昧さが生じない。
- トータルは区分の充足と独立に数える。
