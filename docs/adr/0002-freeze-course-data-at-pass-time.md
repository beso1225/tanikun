# 合格した履修は、合格時点の科目情報を凍結して保持する

## Status

accepted

## 決定

履修が合格した時点の科目情報（単位数など）をその履修に写し取って保持する。以後マスタが改訂されても、集計に使う値は合格時点のまま変わらない。

## 背景

科目マスタは改訂されうる（単位数の変更など）。もし履修が常にマスタの現在値を参照すると、過去の合格の単位数が書き換わり、卒業要件の集計が遡って変わってしまう。履修の記録は履歴であり、当時の事実を保つ必要がある。

## Consequences

- 履修は科目への参照と、合格時点の科目情報の写しの両方を持つ。
- マスタの改訂は既存の合格の集計に影響しない。
